# Project Statement

## Problem Statement
Small clinics and hospitals often track patients, appointments and bills on paper or scattered notes. This is slow, error-prone, and makes it hard to quickly find a patient's details or check their status. This project provides a simple program that keeps these basic hospital tasks in one place.

## Scope of the Project
**In scope**
- Registering and updating patient records
- Searching patients by ID and viewing all patients
- Booking appointments with doctors
- Generating a bill from doctor fee, medicine cost and room rent
- Tracking admission status (Admitted / Discharged)
- Basic input validation for numeric fields

**Out of scope (current version)**
- Permanent storage (database or files); data lasts only while the program runs
- User login and role-based access
- Graphical interface or web interface
- Doctor scheduling conflicts, insurance, or pharmacy inventory

## Target Users
- Hospital reception and administrative staff
- Small clinics needing a lightweight patient record tool
- Students learning how a management system is structured in Python

## High-Level Features
1. Patient registration with duplicate-ID check
2. View all patients
3. Search patient by ID
4. Update patient details
5. Appointment booking
6. Billing
7. Patient discharge
8. Menu-driven command-line interface
